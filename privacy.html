Privacy Policy

Last updated: November 22, 2026

BeamNG Video Agent is a personal tool used only by its owner on the owner's own computer.

What data is accessed

With the owner's permission, the app uses the YouTube Data API scope youtube.upload to upload videos to the owner's own YouTube channel. It does not read, collect or store any other Google account data.

Storage

The OAuth token is stored only on the owner's computer. No data is sent to any server other than Google's YouTube API. No data is sold or shared with third parties.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
